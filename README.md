Basketball Contest Ticket Sales System

Project Description:
This is a client-server desktop application designed to manage ticket sales for a basketball contest.
It allows ticket sellers to log in, view match details, process ticket sales, and search for matches with available seating. 

Solution Organization:
-Model: Contains the domain entities with each respective interface-implementation(Match, Employee, Ticket, Stadium, Team).
-Repository: Contains the data access layer interfaces and implementations using a relational database.
